# Website and README media

```text
assets/
├── images/
│   ├── prism-architecture.png
│   ├── qualitative-results.png
│   └── comparison_2x4_ppt-poster.jpg
└── videos/
    └── comparison_2x4_ppt.mp4
```

- `prism-architecture.png` is the paper architecture figure used by the README
  and project page.
- `qualitative-results.png` is the static qualitative comparison used by the
  README.
- `comparison_2x4_ppt.mp4` is the project-page comparison video; its poster is
  generated from the same video.

Keep website media in these subdirectories rather than at the repository root.
Use descriptive, lowercase filenames for any new assets.
